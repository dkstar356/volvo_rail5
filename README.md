# VOLVO 6번째 지면 광고 — GitHub Pages 게시용

## 파일 배치

- index.html: IPTV 홈 화면
- volvo-detail.html: 볼보 광고 상세화면
- assets/images/: 화면 이미지 및 광고 사진
- assets/video/volvo_xc90.mp4: 광고 영상
- .nojekyll: 정적 파일 게시 설정

## 업로드

1. ZIP을 압축 해제합니다. ZIP 자체를 업로드하지 마세요.
2. 압축 해제한 폴더 안의 파일과 assets 폴더를 저장소 루트에 함께 업로드합니다. 기존 메인배너/5지면 샘플과는 별도 저장소로 관리할 수 있습니다.
3. 파일을 개별 업로드하는 경우, 이미지는 반드시 assets/images 폴더 안에, 영상은 assets/video 폴더 안에 업로드합니다. 파일명을 변경하지 마세요.
4. 폴더를 만들기 위해 빈 이미지·영상 파일을 만들지 마세요. 폴더가 필요하면 assets/images/keep.txt 또는 assets/video/keep.txt를 만든 다음 실제 미디어 파일을 업로드합니다.
5. 브라우저로 업로드한다면 100개 이하씩 나눠 업로드하세요. 파일이 많으므로 GitHub Desktop으로 전체 폴더를 복사해 Commit/Push하는 방식도 가능합니다.
6. Settings → Pages에서 업로드한 브랜치(예: main)와 /(root)를 게시 대상으로 선택합니다.
7. 배포가 완료되면 게시 URL을 엽니다. 이전 화면이 남아 있으면 강력 새로고침(Ctrl+F5)을 합니다.

## 조작

- 홈에서 ↓ 5회: 6번째 [AD] For Life. VOLVO 지면
- ←/→: 볼보 콘텐츠 8개 사이 포커스 이동
- OK/Enter: 선택한 볼보 콘텐츠의 상세화면 진입
- 상세화면에서 Enter 또는 재생하기 버튼: 영상 재생
- 상세화면에서 ESC 또는 ←: 영상 정지 후 홈 6번째 지면의 선택했던 콘텐츠로 복귀
- 상세화면의 홈 버튼: 동일한 홈 복귀

이미지·영상은 원본 데이터를 그대로 분리했으며 재압축하지 않았습니다. index.html 하나만 옮기면 이미지가 표시되지 않으므로 assets 폴더를 함께 유지하세요.
